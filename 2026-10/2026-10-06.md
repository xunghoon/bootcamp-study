## 오늘 한 것

- ### python 학습
  - RAM: 휘발성 메모리
  - HDD/SSD: 비휘발성 저장장치
  - 실행 중인 프로그램은 메모리 자원을 사용한다
  - 파이썬은 라인 단위로 실행
  - 변수 이름에 자료형을 고정하지 않고, 객체가 자료형을 가진다
  - 데이터 타입
    - number(int, float)
    - string
    - boolean(True, False)
    - tuple () : 순서 O, 인덱싱 O, 요소 변경 불가
    - list [] : 순서 O, 인덱싱 O, 요소 변경 가능
    - dictionary {키:값} : 키를 이용해 값에 접근, 키는 중복 불가
    - set (), {} : 중복 불가, 인덱싱 불가, 순서에 의존하지 않음

## 어려웠던 것

- RAM이 왜 휘발성 저장장치인지 어떤 구조인지 봤는데 상당히 어려웠음(전기적인 상태를 이용해 데이터를 유지하는데 왜 전원이 끊기면 그 상태를 유지할 수 없는지)
- HDD/SSD가 왜 비휘발성 저장장치인지 어떤 구조인지 봤는데 상당히 어려웠음(HDD의 자성 물질의 자기화 방향으로 데이터 기록, SSD 플래시 메모리의 전하 상태로 데이터를 기록하는 부분)

## 느낀 점

- RAM이나 CPU, HDD, SSD가 실제로 어떻게 연결되어 프로그램이 돌아가는지 큰 그림이 궁금했다. (주말에 자료를 찾아봐야겠다)
- 파이썬 언어가 익숙해질 수 있도록 많이 쳐봐야겠다
